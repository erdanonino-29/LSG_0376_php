# 01_01 Variables i Tipus de Dades

## Descripció
Aquest exemple mostra com declarar i utilitzar diferents tipus de variables en PHP.

## Contingut
- **variables.php**: Fitxer principal amb exemples de tots els tipus de dades bàsics en PHP.

## Tipus de dades demostrats
1. **String**: Cadenes de text (amb cometes dobles o simples)
2. **Integer**: Números enters
3. **Float/Double**: Números decimals
4. **Boolean**: Valors vertader (true) o fals (false)
5. **Array**: Col·leccions de valors

## Com executar
```bash
php variables.php
```

O accedeix al fitxer a través d'un servidor web (Apache, Nginx, etc.)

## Funcions utilitzades
- `echo`: Per mostrar text
- `gettype()`: Per obtenir el tipus d'una variable
- `implode()`: Per convertir un array a string
