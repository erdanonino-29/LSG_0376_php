# 01_02 Funcions Bàsiques

## Descripció
Aquest exemple mostra com crear i utilitzar funcions en PHP, des de funcions simples fins a funcions amb paràmetres i tipus de retorn.

## Contingut
- **funcions.php**: Fitxer principal amb exemples de diferents tipus de funcions.

## Tipus de funcions demostrades
1. **Funció simple**: Sense paràmetres ni retorn
2. **Funció amb paràmetres**: Rep dades externes
3. **Funció amb retorn**: Retorna un valor amb `return`
4. **Funció amb valor per defecte**: Paràmetres opcionals
5. **Funció que retorna array**: Retorna múltiples valors
6. **Funció amb tipus definits**: Type hints de PHP 7+

## Com executar
```bash
php funcions.php
```

O accedeix al fitxer a través d'un servidor web (Apache, Nginx, etc.)

## Conceptes clau
- `function nom_funcio()`: Declarar una funció
- `return`: Retornar un valor
- `$param = "valor"`: Valors per defecte
- `int $a`: Type hints per paràmetres
- `: int`: Type hints per retorn
