# 02_01 Condicionals If-Else

## Descripció
Aquest exemple mostra com utilitzar les estructures condicionals if, else i elseif en PHP per prendre decisions en el codi.

## Contingut
- **ifelse.php**: Fitxer principal amb exemples de condicionals.

## Estructures demostrades
1. **If simple**: Executa codi si es compleix una condició
2. **If-Else**: Executa codi alternatiu si no es compleix la condició
3. **If-Elseif-Else**: Múltiples condicions en cascada
4. **Condicionals niuats**: Condicionals dins d'altres condicionals
5. **Operador ternari**: Forma curta de if-else `condició ? valor_si : valor_no`
6. **Operadors lògics**: AND (&&), OR (||), NOT (!)
7. **Null coalescing**: Operador ?? per valors per defecte

## Com executar
```bash
php ifelse.php
```

## Operadors de comparació
- `==`: Igual a
- `===`: Igual a (tipus i valor)
- `!=`: Diferent de
- `<`: Menor que
- `>`: Major que
- `<=`: Menor o igual
- `>=`: Major o igual
